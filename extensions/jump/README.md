# Damln Jump

Keyboard navigation and selection for VS Code.

| Shortcut | Action |
| --- | --- |
| `Option+Q Option+Q` | Jump to word start |
| `Option+Q Option+W` | Jump to word end |
| `Option+Q Option+E` | Select to word start |
| `Option+Q Option+R` | Select to word end |
| `Escape`, `Space`, `Enter` | Exit jump mode |

See [package.json](package.json) for commands and default bindings.
